# Fixtures

Test data, held once at the repository root and read by every test target
through `Fixtures.swift`'s upward search rather than copied into each package's
resource bundle.

## structures/

| File | Source | Licence | Why it is here |
|---|---|---|---|
| `AF-P69905-F1-model_v6.pdb` | AlphaFold DB, `AF-P69905-F1-model_v6` | CC BY 4.0 | The reference prediction: 142 residues, one chain, pLDDT in the B-factor column |
| `AF-P69905-F1-model_v6.cif` | AlphaFold DB, same model | CC BY 4.0 | The same model in the other format, so the two readers can be cross-checked atom for atom |
| `1bab.pdb` | PDBe entry 1BAB | CC0 | A real experimental entry: four chains, 266 waters, haems, sulphates, an acetyl cap and four alternate locations |
| `1bab.cif` | PDBe entry 1BAB | CC0 | The same entry in mmCIF, for the same cross-check on an experimental file |

The two cross-format pairs are the strongest tests in the parse suite: they
compare one reader against the other rather than against a number written down
by hand, so a mistake in either shows up without anyone having to predict it.

## structures/edge/

Hand-written, generated by column position rather than by joining fields.

| File | What it exercises |
|---|---|
| `altloc_occupancy.pdb` | The MINOR conformer appears first with the lower occupancy, so first-seen and last-seen policies both give the wrong answer |
| `no_element_column.pdb` | Lines truncated at column 66, leaving atom-name column alignment as the only way to tell an alpha carbon from a calcium ion |
| `two_models.pdb` | An ensemble; model 2 is translated 50 A so the surviving coordinate says which model won |
| `polymer_with_heteroatoms.pdb` | Waters, a haem iron and a zinc ion mixed into a real chain |
| `cif_quoting.cif` | Quoted values, a semicolon text field containing a `#` and a `loop_`, comments, and a second loop after `atom_site` |
| `cif_label_only.cif` | An mmCIF with no `auth_*` columns, forcing the `label_*` fallback |
